# Выполнение плана секретов и ssh-agent

Дата: 2026-10-29. Реализация Tasks 1–12 добавлена; итоговые результаты проверок — ниже.
План: `2026-10-29-crypt-secrets-agent.md`. Использован executing-plans, без git и субагентов.

## Что реализовано

- Генератор паролей OsRng (длина, классы, исключение похожих символов), RFC 6238 SHA1/SHA256/SHA512 и разбор base32/otpauth.
- SSH: ed25519, ECDSA P256/P384, RSA; OpenSSH, PEM/PKCS8, расшифровка при импорте, нормализация, отпечатки, подписи RSA SHA1/SHA256/SHA512. Приватный ключ, публичная часть и комментарий сохраняются атомарно в записи.
- IPC значений, скрытие чувствительных данных в overview, отдельные метаданные истории, Rust-копирование с ConcealedType и очисткой по changeCount. TOTP seed не раскрывается и не копируется.
- Импорт ~/.ssh: верхний уровень, ограничение размера, пропуск мусора/спецфайлов, проверка канонического родителя, обнаружение дубликатов и ошибки по каждому файлу. Исходные файлы не меняются.
- ssh-agent: протокол, Unix-сокет, права/uid, процесс клиента, сериализация подтверждений, доверие на ключ, сброс при блокировке, кэш публичных ключей в Keychain и временное открытие Vault для подписи без разблокировки интерфейса.
- Меню-бар, скрытие окна/Dock, явный выход, один экземпляр, автозапуск --hidden, настройки агента и SSH config. Ошибка запуска агента показывается в настройках и не мешает открыть хранилище.
- Список и карточки секретов, локальное раскрытие на 30 с, история, генератор, TOTP, SSH-секция и чипы, диалог импорта, настройки, подсказка онбординга. Значения/история dev-мока не попадают в localStorage; SSH и TOTP браузерного мока демонстрационные.

## Решения

1. Скрипты skill, использующие git/worktree/SHA, заменены локальным журналом; ревью авторское по требованию пользователя. Цена: нет git-истории и независимого ревью.
2. Неверная команда плана `cargo test -p crypt-desktop secrets clipboard settings` заменена полной desktop-suite. Цена: более долгий запуск, покрытие не уменьшается.
3. Модуль генератора называется `r#gen` (Rust 2024). TOTP использует hmac 0.13 и sha1/sha2 0.11, существующая криптография — sha2 0.10. Цена: две версии digest/sha2.
4. Во время отсутствия зависимостей независимые Tasks 5/7 и модуль буфера выполнялись раньше остальных. Цена: временная неполная интеграция; после пользовательского cargo fetch блокер устранён.
5. Логи `.superpowers/sdd/2026-10-29-crypt-secrets-agent/` сохранены, поскольку git запрещён. Цена: временные артефакты остаются на диске.
6. В ssh-key 0.6.7 преобразование RSA передаёт p дважды; используется явное преобразование через rsa с p и q. Для legacy ssh-rsa wire-фрейм формируется явно: ssh-key отвергает SHA1 Signature. Подписи проверяются независимо через RSA verifier. Цена: совместимость с дефектом зависимости нужно учитывать при обновлении.
7. Старый macOS PEM с явными параметрами EC нормализуется только при точном совпадении сохранённой публичной точки с точкой, вычисленной проверенной библиотекой для NIST P256/P384. Цена: такой PEM без публичной точки отклоняется.
8. Проверки реального UnixListener и Chrome ограничены средой. Сокетный тест не помечен ignored и не ослаблен: его запуск запрошен в обычном терминале пользователя. Остальная suite запускается с явно указанным --skip. Цена: полную нативную приёмку нужно подтвердить вне песочницы.

## Саморевью и исправления

Проверены все пять Review Focus: новое содержимое буфера, параллельные подписи, заблокированное хранилище, мусор в ~/.ssh, обратимость SSH config. Авторское ревью слабее независимого.

Регрессии с воспроизведением RED→GREEN:

- Некорректный base32-паддинг: строгий padded/unpadded декодер.
- Коллизия временного файла: чужой файл больше не удаляется при ошибке create_new.
- Симлинк config: обновляется цель, симлинк сохраняется.
- FIFO при сканировании: чтение открывается с O_NONBLOCK, спецфайлы отбрасываются.
- Ошибка автозапуска после изменения агента: внешние эффекты откатываются, предпочтения сохраняются после успешного применения; обновления сериализуются.
- Конфликт сокета при старте: приложение продолжает работать с доступным хранилищем, ошибка видна в настройках.
- Публичные значения сохраняются при blur; чувствительные черновики требуют явного сохранения.
- Видимость поля ввода пароля автоматически возвращается к password через 30 с.
- Неблокирующий режим принятого соединения на Darwin: клиентский worker явно переключает stream в блокирующий режим. Два запроса с паузой проверяются через UnixStream::pair (воспроизведение BrokenPipe до исправления).
- Для --hidden окно изначально создаётся невидимым, обычный запуск явно показывает его. Ручная проверка поведения остаётся ниже.

## Ручная приёмка на macOS

Эти проверки не выполнялись агентом и нужны с настоящим интерфейсом/Touch ID:

- Импортировать тестовый ключ; `SSH_AUTH_SOCK="$HOME/Library/Application Support/dev.crypt.app/agent.sock" ssh-add -l`: отпечаток и название совпадают с карточкой.
- Подпись в ssh/git с Touch ID; при блокировке Vault подпись проходит после подтверждения, интерфейс остаётся заблокированным.
- Отмена Touch ID возвращает отказ, ssh переходит к следующему способу входа; при отключённом быстром входе показывается экран разблокировки.
- Два параллельных ssh: один диалог одновременно; окно доверия действует на ключ и сбрасывается при блокировке.
- Закрыть окно: Dock скрыт, агент продолжает отвечать; меню «Открыть Crypt» и повторный запуск возвращают окно. ⌘Q / «Выйти» завершают приложение.
- Включить автозапуск и проверить вход в macOS: Crypt стартует без показа окна.
- Скопировать пароль и проверить в другом приложении: через заданный срок буфер пуст; если скопировать своё, оно сохраняется. Проверить ConcealedType с используемым менеджером буфера.
- Добавить/убрать блок ~/.ssh/config, проверить `ssh -G host | grep identityagent`, бэкап, пользовательские настройки и повторное добавление.
- В браузерном моке: вкладки/создание/генерация/30-секундное скрытие/история/чипы; импорт трёх кандидатов, неверный пароль только у своей строки, повтор; настройки после перезагрузки. Браузерная автоматизация в этой среде недоступна.
