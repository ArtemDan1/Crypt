## Проверки

После каждой задачи выполнялись в `apps/desktop`: `pnpm vitest run`, `pnpm build`, `pnpm prettier --check src`; в корне — `cargo test`. Полный cargo test требует выхода из песочницы для Unix-сокета ssh-agent. В Task 4 бэкапа коммит ошибочно создан до окончания полного прогона; сам прогон затем завершился PASS, нарушение записано в журнал.

Не запускать `cargo fmt` по всему workspace. При необходимости форматировать только конкретные изменённые Rust-файлы. Не снимать проверки и не менять намеренно сохраняющий секреты контракт `restore_snapshot`/`revert_record` без отдельного решения владельца.

## Что исправлено после ревью

- Все UI-запросы блокировки идут через Rust-координатор: запрос сохранения только в `main`, ack только от `main` с токеном текущего запроса, таймаут 500 мс. Параллельные запросы сериализованы.
- Только главное окно управляет idle timer; трей передаёт активность и получает отсчёт событиями. Изменение интервала больше не конфликтует со скрытым окном.
- Снимок после неудачного импорта сохраняется при изменении CRDT-ревизий, даже без изменения числа записей.
- Только QR допускают несколько файлов; лишние CSV/JSON отвергаются, неимпортированный файл не уходит в Корзину.
- OTP-сопоставление не принимает произвольный поддомен за имя сервиса; неоднозначность создаёт новый секрет.
- Именованный PIN-профиль сбрасывает несовместимые настройки; причины пропусков CSV доступны даже при нуле новых логинов.
- Инспекция бэкапа возвращает размер файла вместе с заголовком.

## Осталось незавершённым

1. Ручная проверка в `pnpm tauri dev`: положение/закрытие трея, Touch ID/PIN, Finder/Корзина, нативный drag-and-drop; реальный CSV Safari/Chrome, два QR Google Authenticator, зашифрованный Aegis, цикл бэкап → восстановление в **изолированной** папке данных.
2. Визуальный обход всех экранов в обеих темах и с системным reduced-motion. Контраст muted-foreground проверен численно: светлая тема background/card 5.31/5.55, тёмная 6.84/6.24.
3. Deferred minor: `Generator.vue` не инвалидирует поздний ответ генерации при beforeLock/unmount. Видимое раскрытие на экране блокировки не подтверждено; замечание оставлено владельцу по правилам единого прохода ревью.

Ограничения: вставка QR из буфера намеренно скрыта (выбор PNG/JPEG доступен); предпросмотр OTP истекает через 5 минут; прогресс бэкапа неопределённый, без фиктивного процента. Снимки **не откатывают значения секретов**: частично прикреплённые TOTP нужно убрать вручную. Это прежний защитный контракт ядра, а не обещание полного отката импорта.
