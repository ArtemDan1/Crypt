# Crypt: редизайн «Печать»

Дата: 2026-10-31
Статус: на согласование
Макеты: https://claude.ai/artifact/PCSwUujPE9RMxKYTJeKVua (страница «Печать · экраны»; файлы макетов — `project/*.dc.html` внутри артефакта)

## Зачем

Сейчас приложение — стандартная тема shadcn (zinc) с иконкой «C с точкой», которая ничего не говорит. Цель — сохранить минимализм, но дать Crypt собственное лицо: тёплые нейтрали, один фирменный цвет, понятный значок и немного движения, чтобы интерфейс ощущался живым, а не «скучным».

Ориентиры по ощущению (от владельца): Linear, Things, Obsidian — чистые и спокойные.

## Цели

1. Новая тема «Печать» в светлом и тёмном варианте (токены ниже).
2. Новый значок «Семя» для приложения, трея и внутри интерфейса.
3. Переработка всех экранов по макетам: онбординг, разблокировка, сайдбар, файлы/недавние, запись, таблица типа, секреты, конструктор типов, настройки, корзина.
4. Анимации и микро‑интерактивность по всему приложению (список ниже).

## Не цели

- Новая бизнес‑логика в Rust‑ядре (`crates/crypt-core`) и новые поля в модели данных.
- Смена стека: остаются Vue 3, Tailwind 4, shadcn‑vue/reka‑ui, lucide.
- Смена шрифта: остаётся Geist / Geist Mono.

## Анти‑цели (провал, даже если «работает»)

- Акцентный цвет везде: изумрудный — только для основных действий, активных состояний и фокуса. Интерфейс в целом остаётся нейтральным.
- Янтарь вне секретов. Янтарный цвет означает только «здесь секрет» (значения, бейджи, иконки секретов, предупреждение про сид‑фразу).
- Анимации, которые мешают: всё короче 500 мс (кроме петель вроде сканирования Touch ID и таймера TOTP), ничего не блокирует ввод, `prefers-reduced-motion` отключает движение.
- Регрессии в безопасности: раскрытие секретов, очистка буфера, автоблокировка работают как сейчас.

## Экраны

Ниже — что должно получиться на каждом экране. Детали вёрстки, отступы и тексты — в соответствующем макете; при расхождении текста здесь и в макете прав этот документ.

### Сайдбар (`AppSidebar.vue`, макет `Sidebar.dc.html`)
- Сверху: зона перетаскивания окна, справа кнопка блокировки. Вокруг иконки замка — тонкое кольцо, показывающее остаток времени до автоблокировки. Таймер живёт во фронте (`lib/idle.ts`, `stores/session.ts`): добавить в `idleTimer` отдачу остатка (например, `remaining()` или время следующего срабатывания) и обновлять кольцо раз в секунду. Rust не трогаем. При «Никогда» кольца нет.
- Блок хранилища: `CryptMark`, название «Личное», число записей, изумрудная кнопка «+» (новая запись).
- Поиск ⌘K.
- Разделы: Недавние, Секреты (янтарная иконка), Типы (с цветной плиткой‑иконкой типа), «Настроить типы», Файлы (дерево), Теги — чипами в строку, а не списком.
- Низ: Корзина со счётчиком, иконка Настроек.

### Файлы и недавние (`Directory.vue`, `Home.vue`, макет `Directory.dc.html`)
- Корень `/` показывает: блок «Недавние» (4 карточки), «Папки» (плитки), «Записи» корня.
- Решение исполнителя: `/recent` остаётся маршрутом, но пункт «Недавние» в сайдбаре ведёт на `/`; если это ломает текущие сценарии — оставить `/recent` как есть, со стилем карточек.
- Переключатель «списком / карточками» для записей, выбор запоминается (localStorage).
- Хлебные крошки, переход в папку с анимацией появления содержимого.

### Запись (`Record.vue`, макет `Record.dc.html`)
- Чипы типа и тегов над заголовком; «+ тег» — пунктирный чип.
- Поля: сетка «иконка вида + название / значение», подсветка строки при наведении, кнопка копирования появляется при наведении для текстовых полей.
- Ссылка на секрет — янтарный чип; ссылки на записи — чипы с иконкой файла.
- Статус сохранения: спиннер «Сохраняется…» → галочка «Сохранено · ЧЧ:ММ».
- Правая панель (бэклинки, мини‑история, даты) сворачивается кнопкой в заголовке с анимацией ширины; состояние запоминается.
- Wiki‑ссылки в теле — мягкий изумрудный фон. Чекбоксы задач — анимированная галочка и зачёркивание.

### Таблица типа (`TypeTableView.vue`, макет `Table.dc.html`)
- Заголовок с плиткой типа, кнопки «Поля типа» и основная «Новая …».
- Виды — вкладки с бегущим подчёркиванием; сохранённые фильтры — мягкие изумрудные чипы.
- Стрелка сортировки поворачивается; строка при наведении показывает стрелку «открыть».
- Новая строка появляется с короткой подсветкой.
- Звёзды рейтинга в макете — только пример: отдельного вида поля «оценка» в коде нет, числовые поля показываются числом. Сохранённые виды — это `ViewDef.config`, вкладки строятся по ним.

### Секреты (`Secrets.vue`, `secret/*`, макет `Secrets.dc.html`)
- Список: фильтры видов — «таблетки» со счётчиками; элементы с янтарной плиткой‑иконкой вида.
- Деталь: значения в янтарной плашке; раскрытие — из размытия; копирование — тост «… скопирован · очистится через N с» (N из настройки).
- TOTP: кольцо обратного отсчёта и смена кода с анимацией (`TotpCode.vue`).
- Генератор пароля — поповер с длиной, переключателями и анимацией нового значения (`PasswordGenerator.vue`).
- Индикатор надёжности пароля — простая эвристика на фронте (длина + классы символов), без внешних библиотек. Показывается **только когда значение уже есть во фронте**: после раскрытия или в генераторе. Значение ради подсчёта не запрашивается (решение исполнителя‑дизайнера: иначе открытый текст попадает в webview без действия пользователя).
- Карта — визуальная «карточка». Номер (`sensitive`) маскируется **полностью** (`•••• •••• •••• ••••`), пока его не раскроют; последние 4 цифры в списке и на карточке не показываются. Срок и держатель берутся из `SecretOverview.public`. В списке подзаголовок — «до ММ/ГГ». SSH‑ключ — отпечаток, публичный ключ, переключатель ssh‑agent.

### Конструктор типов (`Types.vue`, макет `Types.dc.html`)
- Поля — карточки с ручкой перетаскивания, плиткой‑глифом вида и вариантами для «Выбора».
- «Добавить поле» — поповер‑сетка видов; новое поле появляется с подсветкой.
- Справа — предпросмотр записи, обновляется сразу.
- Выбор цвета типа в макете требует нового поля в `TypeDef` — **не делать** (см. не цели); плитка типа берёт цвет по иконке/порядку.

### Настройки (`Settings.vue`, макет `Settings.dc.html`)
- Разделы слева: Безопасность, Секреты и SSH, Хранилище, Опасная зона; бегущая метка активного раздела.
- Сегментные переключатели (автоблокировка, очистка буфера) со скользящим индикатором.
- Показ сид‑фразы: подтверждение → слова появляются по очереди → полоса обратного отсчёта 60 с.
- Удаление хранилища: кнопка неактивна, пока не введено «УДАЛИТЬ»; при попытке — тряска поля.
- Метки «автоматически» у снимков в макете — пример; показывать только то, что реально есть в данных.

### Корзина (`Trash.vue`, макет `Trash.dc.html`)
- Действия строки появляются при наведении; «Удалить навсегда» подтверждается прямо в строке.
- Восстановленная запись уезжает вправо, удалённая сжимается; тост с папкой назначения.
- Пустое состояние с иллюстрацией.

### Разблокировка (`Unlock.vue`, макет `Unlock.dc.html`)
- `CryptMark` с лёгким «парением»; Touch ID — кнопка с ореолом, сканирующей полосой и кольцами во время проверки.
- PIN — ячейки с подсветкой текущей, точки появляются с «прыжком»; ошибка — тряска и красные ячейки.
- Успех — короткая анимация значка, затем переход (не отдельный экран «Хранилище открыто» — это только в прототипе).
- Вход по сид‑фразе — со счётчиком слов.

### Онбординг (`Onboarding.vue`, макет `Onboarding.dc.html`)
- Слева тёмная панель: значок, слоган, вертикальные шаги с линией прогресса; справа шаг.
- Сид‑фраза сначала скрыта («Показать фразу»), слова появляются по очереди; чекбокс «Я записал(а) фразу» разблокирует «Проверить». Кнопки «Скопировать» и «Распечатать» остаются (печать — существующий `.seed-sheet`).
- Проверка слов — галочка/красная рамка по мере ввода.
- Быстрый вход — как сейчас, плюс подсказка совпадения PIN.

### Трей (макет `Tray.dc.html`) — решение владельца: как в макете
Нативное меню (`tray.rs`) заменяется собственным всплывающим окном под значком трея (отдельное маленькое окно Tauri без рамки, ~340 px шириной, закрывается при потере фокуса и по Esc).
- Хранилище открыто: поиск по секретам; «Быстро скопировать» — список секретов (логины: пароль; TOTP: текущий код с кольцом отсчёта; токены; публичный SSH‑ключ). Клик копирует значение через существующий путь копирования (с очисткой буфера), строка показывает «Скопировано». Хоткеи ⌘1…⌘9 для первых строк.
- Какие секреты в списке: решение исполнителя‑дизайнера — недавно использованные, до 6 штук; поиск ищет по всем секретам.
- Строка статуса: ssh‑agent (работает/выключен, число ключей) и остаток до автоблокировки.
- Действия: «Открыть Crypt» (⌘O), «Заблокировать» (⌘L), «Выйти» (⌘Q — в макете нет, но пункт из текущего меню сохранить).
- Хранилище заблокировано: кнопка Touch ID в окне трея; после разблокировки — список.
- Окно трея не держит значения в своём состоянии дольше, чем нужно для копирования.

### Генератор паролей (макет `Generator.dc.html`) — решение владельца: отдельная кнопка, «как в KeePass»
Кнопка «Генератор» в шапке «Секретов» открывает отдельный экран (маршрут, например `/generator`). Встроенный поповер‑генератор в поле пароля остаётся и использует ту же логику.
- Режим «Символы»: длина 4–64 (ползунок + число); наборы: заглавные, строчные, цифры, минус, подчёркивание, пробел, спецсимволы, скобки, латиница‑1; «исключить похожие» (O0Il1|); «каждый выбранный набор хотя бы раз»; поля «добавить символы» и «исключить символы».
- Режим «Фраза»: число слов 3–12, разделитель (‑ . пробел _), с заглавной, число в конце. Словарь — EFF large wordlist (7 776 слов), встраивается в приложение.
- Стойкость в битах (символы: длина × log2 размера набора; фраза: слова × log2 7776 + добавки) и подпись «слабый/средний/надёжный/очень надёжный» (пороги 50/75/100 бит).
- Профили‑пресеты: «Стандартный», «PIN 6 цифр», «Wi‑Fi», «Фраза 5 слов». Пользовательские профили — не в этом объёме.
- Пять дополнительных вариантов справа; «Скопировать» (с очисткой буфера) и «Сохранить как секрет» (новый секрет‑логин с этим паролем, открывается для заполнения).
- Генерация — криптостойкий ГСЧ. Где считать (фронт `crypto.getRandomValues` или существующий `crates/crypt-core/src/gen.rs`) — решение исполнителя; логика одна для экрана и поповера.
- Последние настройки генератора запоминаются.

## Движение

Общие правила: длительности 150–450 мс, кривая `cubic-bezier(.2,.8,.2,1)` для появления и `cubic-bezier(.3,1.3,.5,1)` для «пружинящих» индикаторов; `prefers-reduced-motion: reduce` отключает всё, кроме смены прозрачности.

Обязательный набор:
- смена темы — плавная смена цветов (~350 мс);
- появление содержимого при смене маршрута/папки/записи — подъём на 8–10 px с проявлением;
- поповеры и меню — масштаб от 0.97 с проявлением;
- тосты — снизу с лёгкой пружиной;
- сегменты/вкладки — скользящий индикатор;
- переключатели — пружинящий бегунок;
- раскрытие секрета — из размытия;
- Touch ID — сканирование и кольца; PIN — тряска при ошибке;
- TOTP — кольцо отсчёта;
- нажатие кнопок — `scale(.97)`.

Где жить анимациям — на усмотрение исполнителя (CSS‑утилиты в `styles.css`, `tw-animate-css`, Vue `<Transition>`); без новых тяжёлых зависимостей.

## Ограничения

- Tauri 2, macOS; окно с собственной зоной перетаскивания (`data-tauri-drag-region`) — сохранить.
- Браузерный режим `pnpm dev` с фейковым бэкендом должен продолжать работать — по нему удобно сверять с макетами.
- Существующие тесты (`pnpm test`) зелёные; `pnpm format:check` проходит.
- Доступность: интерактивное — настоящие `button`/`a`, `aria-label` у кнопок‑иконок, контраст текста ≥ 4.5:1 в обеих темах.
